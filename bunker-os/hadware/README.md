# Directorio `hadware`

Este directorio está mantenido por compatibilidad con versiones anteriores.
Toda la detección y optimización de hardware se encuentra en:

```
hardware/hal.sh
```

Use `bunker hardware detect` o `bunker engine-flags adapt` para detectar y
optimizar el hardware del sistema.
